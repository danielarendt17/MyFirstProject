# MyFirstProject
Grade Reader

## How to Run
1. Open IDE
2. Create project named **Grade Reader**
3. Add Main.java folder to the project
4. Add **grades.txt** file with included student names and grades

## Purpose of Program
This program was made to read out a list of students names and their grades from a text file.

## Example of grades.txt Format
```text
Bob: 95% A
Sarah 99% A
Jared 71% C
Daniel 50% F
```

## Example Output
```text
Bob: 95% A
Sarah 99% A
Jared 71% C
Daniel 50% F
```
